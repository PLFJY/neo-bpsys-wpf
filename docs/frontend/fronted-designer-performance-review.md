# v3 设计器性能审查

本次审查基于 `3a8d4aa2` 检查点，覆盖主设计器的选择、属性网格、图层拖放、几何交互、预览渲染、撤销重做、图片校验、动画目标与窗口生命周期，并检查行为节点图的拖动及本地历史。

## 发现与修复

| 路径 | 原开销或问题 | 当前处理 |
| --- | --- | --- |
| 切换选择 | 清空全部属性行，反复创建复杂 WPF 编辑器模板；重建所有 hitbox | 复用兼容属性行、字体选项和根 hitbox，只更新变化部分 |
| 多选 | 为每个选中控件建立完整属性网格；主项不变时交集可能不刷新 | 按控件类型复用 Schema，仅检查动态编辑能力；集合变化也刷新交集 |
| 选择动画上下文 | 每次选择扫描预览树并重建全部动画目标 | 选择只更新 Self，完整渲染后才重建目标目录 |
| 根几何历史 | 每次微调、拖动起点及其撤销均序列化和解析整个布局及行为文档 | 专属几何历史，只保存涉及控件的几何及 BO 状态 |
| 完整历史 | UTF-16 文本保存大快照，仅限制条数 | UTF-8 字节；主编辑器每栈约 32 MiB、节点图每栈约 16 MiB，同时保留原有 50 步上限及至少最近一步 |
| BO 恢复 | 非当前状态使用基类序列化比较，可能漏掉派生字段并误判为几何变化 | 按配置实际类型比较，保护文本、样式和插件扩展字段 |
| 属性提交 | 重复整份校验和预览请求；普通样式编辑重建全部图层 | 消除重复工作；根几何提交走补丁，其他属性仅更新涉及控件的子节点 |
| 图片校验 | 反复创建 WIC decoder 读取相同文件头 | 有界尺寸缓存，文件元数据失效，逐次重新应用用途限制 |
| 完整预览重绘 | 动画 session 中的 BaseValues 和 overlay 可能引用旧视觉树 | 替换前释放旧动画 session；清空预览也注销完整名称树 |
| Dispatcher | 每条属性通知都排队恢复提交状态，关闭后仍可能有校验等工作等待执行 | 合并同类操作并在结束会话时取消；手动执行验证工作也移除旧的排队回调 |
| 节点拖动 | 每个鼠标事件全图校验、刷新目录；多选时同一连接反复更新 | 拖动期间更新位置及受影响连接，结束事务后校验一次 |
| 节点历史上限 | 原淘汰逻辑可能移除较新的历史 | 从最旧条目淘汰，保留最近历史连续性 |

## 实测

在同一 Windows/.NET 10 Debug 环境中，使用临时 WPF 验证程序：300 个文本配置，每个包含约 2 KiB 文本，预览画布放置对应轻量 Border，并实际创建设计器属性面板、执行测量和布局。表中为操作均值；这不是完整生产渲染或用户运行数小时、占用 1 GiB 时的复现。

| 操作 | 优化前 | 优化后观测 | 每次托管分配变化 |
| --- | ---: | ---: | ---: |
| 单选切换并布局 | 445 ms | 约 8–13 ms | 约 27 MiB → 366 KiB |
| 50 控件多选切换并布局 | 223 ms | 约 52–73 ms | 约 25 MiB → 1.7 MiB |
| 键盘移动 | 13.6 ms | 约 1.4–2.1 ms | 约 2 MiB → 87–115 KiB |
| 移动撤销 | 32.4 ms | 约 1.5–2.8 ms | 约 9 MiB → 125–146 KiB |
| 移动重做 | 29.4 ms | 约 1.0–1.8 ms | 约 8.5 MiB → 119–125 KiB |
| 字号属性提交 | 39.8 ms | 约 12–22 ms | 约 4.7 MiB → 1.5–1.6 MiB |
| 相同图片文件校验 | 0.73 ms | 约 0.08–0.17 ms | 约 1.7 KiB → 0.2 KiB |

优化后的连续鼠标移动，包括吸附、预览几何及选择装饰器更新，观测均值约 0.4–0.6 ms，单次最高约 21 ms。首次切换多选仍出现约 200–276 ms 的样本，均值包含该样本；不能将均值当作所有操作的最大延迟。GC、首次 JIT、字体缓存和实际控件插件都会影响结果。分配量表示操作产生的托管分配，并非进程常驻内存。

## 验证与维护约束

开发验证实际运行完整文档 memento 对照：30 次交错的多选移动、内容修改、自动尺寸修改和 BO 切换，逐次验证撤销与重做结果；检查同主项多选交集刷新、图片用途切换/覆盖/删除失效、大快照预算、节点连续拖动及历史上限。反复打开并关闭三个实际 WPF 编辑器后，通过 WeakReference 与 Dispatcher 排空验证窗口和 ViewModel 可回收。

临时测量和验证代码执行通过后删除，不新增性能测试工程或源文件字符串门禁。永久测试仅在现有 `FrontedDesignerBehaviorTest` 中保留混合几何/内容历史与 BO 派生字段的用户数据回归，防止后续历史格式或恢复规划变更静默丢失修改。

后续维护应继续遵守：选择不读取图片文件；鼠标移动不序列化完整文档、不重建全部预览；一次提交只调度一次必要工作；完整渲染移除名称和动画引用；缓存与历史都有上限。其他内容编辑、子部件编辑及复杂布局/行为修改仍允许完整预览重建，以保留插件生命周期和现有数据契约。大型插件控件的初始化、首次字体/图片载入及长时间实际运行仍需在真实工程中验证，不能用该合成基准承诺所有操作零卡顿。
